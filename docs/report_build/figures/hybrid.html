Hybrid ranking

Two lists become one, then five chunks remain

The weights must sum to 1. AppConfig rejects any other pair. Changing the pool of 20 changes min-max, because the minimum and maximum come from that pool.

Keyword side · weight 0.3

  1. Match query on content.
  2. Take 20 hits.
  3. Min-max only those 20 scores.
  4. A chunk the keyword search missed contributes 0.

Semantic side · weight 0.7

  1. Embed the question.
  2. kNN with 50 candidates, keep 20.
  3. Min-max only those 20 scores.
  4. A chunk the vector search missed contributes 0.
final = 0.3 × norm(BM25) + 0.7 × norm(cosine)
then add 4.0 if a figure or table number matches, or 2.0 for an image chunk on a visual question
