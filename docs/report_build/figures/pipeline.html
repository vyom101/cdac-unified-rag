Two phases, one index

From the PDF file to the stored answer

Indexing and answering are separate. The saved demo did not re-read the PDF. It searched the index that indexing had already filled.

Phase A · once per PDF, before any question
1

Read and identify the PDF

Hash the bytes with SHA-256. Open the file with pypdf. Reject a missing, corrupt, or zero-page file.

IN pathOUT document_id, page count
PDFProcessor.process_pdf
2

Extract every page

Clean the text layer. If fewer than 15 non-space characters remain, try OCR. A failed page is recorded and the next page continues.

IN pageOUT text, blocks, status
clean_extracted_text · OCRProcessor
3

Chunk with pages attached

Pack blocks by heading, up to 1,200 characters, carrying 100 characters of overlap. Merge a short chunk only into the same section.

IN blocksOUT chunks + statistics
Chunker.chunk_structurally
4

Summarise on the CLI path

Three extractive sentences per chunk, then a composite of every 10 summaries. PDFRAGPipeline skips this step.

IN chunksOUT summary records
build_chunk_summaries
5

Embed and bulk-index

Encode in batches of 32. Write text, pages, and the vector. The document _id is the chunk or summary id.

IN recordsOUT rag_corpus_v1
index_corpus
Shared store: Elasticsearch 8.12.2 · index rag_corpus_v1 · 12,054 documents on 11 November 2026 · 6,076 from PDFs
Phase B · every question, on the ask path used by the saved demo
6

Embed the question and search twice

BM25 matches the content field. The vector query uses the same MiniLM model and asks HNSW for 50 candidates.

IN questionOUT pool of 20 + pool of 20
HybridRetriever.search
7

Fuse, then keep five

Min-max each list. Score = 0.3×keyword + 0.7×semantic. A matching figure number can add 4.0.

IN raw scoresOUT top 5
fuse_hybrid_results
8

Gate before the model

Abstain when there are no hits, when the first score is below 0.35, or when a requested role is missing from the text.

IN corpus hitsOUT abstain sentence, or continue
grounding_failure
9

Write the answer and attach sources

Temperature is 0. The demo used Llama 3.2. The sources array is copied from the hits, including page numbers on text chunks.

IN promptOUT RAGAnswer
answer_question
