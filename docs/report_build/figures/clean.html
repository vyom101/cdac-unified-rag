Cleaning

Why the text is rewritten before it is chunked

Running headers would otherwise become the terms BM25 ranks. A hyphen split across a line would miss the query word.

1

Drop illegal controls

Characters below U+0020 are removed. Tab and newline stay.

IN raw extract_textOUT printable text
clean_extracted_text
2

Join a hyphenated line break

A hyphen at the end of a line is removed when the next line continues with a lowercase letter. The illustration is the rule, not a quote from a stored page: “infor-” + “mation” becomes “information”.

IN broken wordOUT joined word
regular expression in clean_extracted_text
3

Collapse whitespace

Runs of spaces become one space. Three or more newlines become one blank line. Each line is stripped.

IN messy spacingOUT paragraph breaks
clean_extracted_text
4

Remove repeated running matter after page 1

Page-number lines, short course-code lines, and a two-to-four-word title-case running head are dropped. Page 1 is left intact so a title survives.

IN page 2+ linesOUT body lines
remove_repeated_boilerplate
5

Drop empty and boilerplate blocks

A block that is mostly those same patterns is not passed to the chunker. Failed pages contribute no blocks.

IN blocksOUT blocks with text
is_boilerplate_block
